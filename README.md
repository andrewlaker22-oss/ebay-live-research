# eBay Live community research: cloud handoff repository

Private working repository for continuing the VaynerMedia eBay Live community research in a cloud Claude session. Start with `CLOUD_START_HERE.md`.

Contents (mirrors the original project's relative paths):

- `CLOUD_START_HERE.md`: what to do next (resume at Stage 3).
- `RESEARCH_CHECKPOINT.md`: current checkpoint (v6). `ANALYSIS_RULES.md`: evidence rules (v2). `HANDOFF_TO_CLOUD_FABLE.md`: file-set notes.
- `analysis_outputs/full_dataset_inventory/`: dataset inventory, Gemini enrichment status, the full-analysis prompts.
- `analysis_outputs/full_collection_analysis/`: Stage 1 and Stage 2 outputs, reading register, derived index and scripts.
- `analysis_outputs/ai_strategy_comparison_150_rows/`: the closed 150-row sample analysis (revision 2.1) and its history.
- `finalized/`: the eight finalized non-brand research CSVs (source data; do not modify).
- `context_uploads/` and `data/.../strategy_email.txt`: client call and internal transcripts, sprint Q&A PDF, strategy email. Client material: keep this repository private.
- `flash_batch_runs/`: QA notes from the Flash labelling runs (notes only, no raw batch files).
- `enrichment_v2_20260927/`: partial targeted-enrichment run outputs, if included.

Not included: downloaded videos (22 GB), raw batch request/response files, exports, logs, the brand-posts dataset, and the application code.

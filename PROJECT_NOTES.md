# eBay Research Project Notes

- Keep updates and recommendations blunt, but not so short that the user loses the shape of the data.
- Use the 80/20 rule: give the core numbers, what the data actually is, and the actual recommendation first.
- Avoid corporate-sounding filler.
- Preferred format:
  - `Simple headline`
  - `3-6 numbers/details that matter`
  - `What to do next`
